# 🎮 4399 村长征战团 自动化助手

> 基于 OpenCV 视觉识别，本地运行的轻量级游戏辅助工具，**仅供学习交流使用，严禁用于商业目的！**

本项目通过纯视觉识别（模板匹配 + OCR）实现游戏界面分析与自动化操作，无需修改游戏内存或网络数据，安全可控。

---

## ✨ 当前功能

| 功能 | 说明 |
|:---|:---|
| 📖 **辅助答题** | 自动识别题目区域，通过 OCR + 本地数据库匹配答案，支持模糊匹配与错字纠正 |
| 🤝 **联盟大厅捐献** | 自动完成联盟大厅的金币、钻石、红钻、将魂捐献，次数可自定义 |
| 🏛️ **科技大厅捐献** | 自动进入科技大厅，对用户勾选的科技依次进行捐献，支持跳过无需捐献的科技 |

> 更多日常任务（如自动收资源、自动出征等）**不定期更新中**，欢迎关注。

## 📦 安装与使用

### 环境要求
- Python 3.10 及以上
- Windows 10/11（推荐）或其他支持 OpenCV 的操作系统

### 安装步骤

```bash
# 1. 克隆或下载项目
git clone https://github.com/your-username/4399czzzt_help.git
cd 4399czzzt_help

# 2. 创建 Python 3.10 虚拟环境（推荐）
conda create -n czzzt_env python=3.10
conda activate czzzt_env

# 3. 安装依赖
pip install -r requirements.txt

# 4. 启动程序
python main.py
```

### 模板图片准备
- 首次使用前，请按 `templates/buttons/` 目录中的示例，截取游戏中的对应按钮图片（如“联盟图标.png”、“捐献按钮.png”等），保存为 PNG 格式。
- 具体截图方法请参考项目文档或视频教程（待补充）。


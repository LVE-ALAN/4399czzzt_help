# 🖥️ 视觉识别自动化控制实验项目

> 基于 OpenCV 视觉识别与 OCR 技术的图形界面自动化实验程序，**仅供个人学习与计算机视觉技术研究使用**。

本项目通过纯视觉识别（模板匹配 + OCR）实现图形界面元素的检测与定位，不修改任何目标软件的内存数据或网络通信，属于**非入侵式**的技术实验。

---

## 🧪 实验功能

| 功能 | 说明 |
|:---|:---|
| 📖 **文字识别与匹配** | 对屏幕指定区域进行 OCR 识别，与本地数据进行匹配查询，演示图像预处理、文字识别与模糊匹配技术 |
| 🖱️ **界面元素定位与操作** | 通过模板匹配定位界面中的特定元素，模拟鼠标点击操作，演示 OpenCV 模板匹配在实际场景中的应用 |
| 🔁 **流程自动化控制** | 演示基于界面状态识别的简单流程自动化，展示状态机与视觉反馈结合的基础实现 |

> 本项目为技术实验性质，**不针对任何特定游戏或软件**，请勿用于违反任何服务条款的场景。

---

## 📦 安装与使用

### 环境要求
- Python 3.10 及以上
- Windows 10/11（推荐）或其他支持 OpenCV 的操作系统
- 可选 NVIDIA 显卡加速（如使用 GPU 版本依赖）；若无独立显卡，可使用 CPU 版本，仅识别速度略有下降，不影响功能。

### 安装步骤

```bash
# 1. 克隆项目
git clone https://github.com/LVE-ALAN/4399czzzt_help.git
cd 4399czzzt_help

# 2. 创建 Python 3.10 虚拟环境（推荐）
conda create -n czzzt_env python=3.10
conda activate czzzt_env

# 3. 安装依赖
pip install -r requirements.txt

# 4. 运行程序
python main.py
```

### 模板图片准备
- 模板匹配需要预先截取目标界面中的特征图片（如按钮、图标等），存放于 `templates/buttons/` 目录下。
